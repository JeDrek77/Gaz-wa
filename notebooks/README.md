# Notebooki

Tu trzymaj eksploracje i eksperymenty.

Proponowany start:

```powershell
uv sync --extra dev
uv run jupyter lab
```

Pierwszy notebook warto poswiecic na:

- sprawdzenie zakresu dat,
- braki i duplikaty,
- rozklady zuzycia,
- zaleznosc zuzycia od temperatury,
- profile godzinowe, dzienne i sezonowe,
- wykrywanie anomalii/postojow.
